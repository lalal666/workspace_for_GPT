## 1. 产品概述

### 1.1 一句话定位

低功耗设计、蓝牙 Mesh 组网的微电网末端交流电流感知节点。

### 1.2 背景与问题

微电网"源—网—荷—储"体系中，末端负荷与末端环路电流检测：

- **末端计量缺失**：网关与集中计量覆盖主干，末端支路无感知，能效管理"看不见、算不清"。
- **改造代价高**：传统电流互感器 + 有线采集需布线、停电、破线，施工成本与停机损失双重承压。
- **场景碎片化**：末端负荷/环路支路众多、电流等级分散，缺少标准化、免施工的采集手段。
- **点位分散**：末端安装点位多而散，有线方案的通信与供电成本随点位线性膨胀。

本产品以"电池 + 钳式 + 蓝牙 Mesh"三要素，把电流检测从"工程改造"降维为"即装即用"的标准化感知节点。

### 1.3 核心价值主张

| 维度   | 价值点                                |
| ---- | ---------------------------------- |
| 免布线  | 钳式非侵入，不停电、不破线、即装即用                 |
| 低成本  | BOM≤30元                            |
| 电流精度 | 磁式互感器（CT），额定区间 **±3%**、小信号 **±5%** |
| 电量精度 | **软件计量综合误差 ±10%**（非结算级，能耗展示与联动参考）  |
| 无缝组网 | 本地自治 + 云端可视                        |

## 2. 市场与用户

### 2.1 目标用户

| 用户角色       | 核心诉求                      |
| ---------- | ------------------------- |
| 微电网/综合能源   | 快速部署末端监测，降低交付成本，缩短并网/验收周期 |
| 工商业园区/楼宇能管 | 末端支路分项计量，支撑能耗诊断与节能改造      |
| 设备增值       | 为自有末端设备附加"可计量"能力，提升产品溢价   |

### 2.2 典型应用场景

1. **楼宇末端负荷支路**：空调、照明、动力设备等交流负荷电流监测，用电行为分析。
2. **楼宇配电末端环路**：分支回路电流监测，过载预警。
3. **楼宇分项计量与节能联动**：照明/空调/动力分项监测，结合楼宇空气质量传感器数据，支撑新风节能与能耗诊断。

### 2.3 竞品与差异化

| 对比维度 | 传统 CT + 有线采集 | 本产品            |
| ---- | ------------ | -------------- |
| 安装   | 需停电、破线、布线    | 钳式非侵入、免停电      |
| 供电   | 有线供电/取电      | 纽扣电池（可换电）      |
| 传感器  | 闭口 CT（需拆线安装） | 开口钳式 CT（免拆线安装） |
| 组网   | 有线 RS485/以太网 | 蓝牙 Mesh 无线     |
| 施工成本 | 高（随点位线性）     | 极低（即装即用）       |

> **产品取舍原则**：以传统成熟的 CT 方案，换取高精度、低成本与免布线部署。目标不是替代集中式高精度计量，而是**消灭末端盲区**。

## 4. 功能需求

### 4.1 功能清单（优先级）

| 编号    | 功能         | 功能描述                                                                                                                                                                                                        | 优先级 | 说明                                                                                  |
| ----- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | ----------------------------------------------------------------------------------- |
| 4.1.1 | 交流电流测量     | 输出交流真有效值+ 瞬时值 + 峰值。<br />交流谐波场景（变频、开关电源负载）下保证有效值精度。<br />量程由钳环规格固定，软件自动量程（不做钳环型号自动识别，设备不更换钳环，量程0-20A）                                                                                                       | P0  | 有效值 + 瞬时值 + 峰值                                                                      |
| 4.1.2 | 电量计量       | **软件计量方式（非结算级）**：设备仅采集并上报电流值，电量由网关/云平台以软件方式合成——`电量 ≈ 电流有效值 × 标称电压 × 时间 × 假定功率因数`。<br />**综合误差精度 ≤ ±10%**（叠加电压偏差、功率因数假设、电流测量误差的综合结果），用于**能耗展示与联动参考**，不作贸易结算。<br />高精度结算场景由网关侧融合电压采集点（其他设备）合成真实功率，本节点提供电流数据源。 | P0  | 电流 × 标称电压 × 功率因数，网关/云侧软件合成，综合误差 ≤ ±10%                                              |
| 4.1.3 | 周期数据上报     | 上报数据帧：设备 ID、时间戳、电流值、电池电压。<br />周期上报降低上报空占比，兼顾实时性与功耗。                                                                                                                                                        | P0  | 可配周期，无线上行网关                                                                         |
| 4.1.4 | 阈值事件触发     | 支持配置电流上限（过流报警）、下限（设备停机）、电流突变幅度阈值。                                                                                                                                                                           | P2  | **受芯片休眠限制**：休眠期不检测电流，阈值判断仅在唤醒窗口内进行（默认 3min 唤醒一次、每次 500ms），唤醒时检测到越限即上报；异常恰逢唤醒态则实时上报。 |
| 4.1.5 | 异常报警       | 包含持续过流告警、回路断线/轻载告警、电池电量低阶（≤20% 预警）。                                                                                                                                                                         | P1  | 过流、断线、电池低电量                                                                         |
| 4.1.6 | 电源开关（拨动开关） | 设备采用拨动开关物理通断电，**上电默认唤醒**，无需多功能按键。<br />1. 拨到 ON：接通电源，上电即默认唤醒进入工作模式；<br />2. 拨到 OFF：物理断电，进入仓储/运输态（零功耗保电）；<br />3. 首次上电（未入网）自动进入入网搜索模式 30s，超时或已入网则恢复正常工作                                                      | P0  |                                                                                     |
| 4.1.7 | 远程配置       | 支持网关广播或单播下发指令修改：采样频率、上报周期、报警门限值等。                                                                                                                                                                           | P1  | 采样周期、上报周期、阈值                                                                        |
| 4.1.8 | OTA 升级     | 1. 支持通过小程序、平台下发OTA；  <br />2 升级中途断电/断网，重启自动回滚旧版本固件                                                                                                                                                          | P0  |                                                                                     |
| 4.1.9 | 能效闭环       | 电流数据 + 楼宇空气质量传感器联动，支撑"检测→分析→节能"闭环                                                                                                                                                                           | P0  |                                                                                     |

## 5. 性能与技术指标

### 5.1 电气性能

| 指标项    | 目标值                                    | 备注        |
| ------ | -------------------------------------- | --------- |
| 检测类型   | 交流 AC                                  |           |
| 量程（分档） | 0-20A                                  |           |
| 测量电流精度 | ±3% （5%~100% 额定）<br />±5.0% （1%~5% 额定） |           |
| 频率范围   | 50/60 Hz                               |           |
| 额定过载   | 1.2倍                                   |           |
| 电量综合误差 | ≤ ±10%（软件计量，非结算级）                      | 能耗展示与联动参考 |

### 5.2 低功耗指标

| 指标项    | 目标值          | 备注                                |
| ------ | ------------ | --------------------------------- |
| 平均功耗   | ≤ 15 µA @ 3V | 唤醒周期 3min（每次 500ms）、上报 15min 典型工况 |
| 休眠电流   | ≤ 3 µA       | 深度休眠                              |
| 采样唤醒电流 | 短时 mA 级      | 唤醒采样 + 运算 < 50ms                  |
| 电池类型   | 纽扣电池CR2450   | 可换电池                              |
| 续航     | ≥ 3 年（典型工况）  | 采样/上报周期拉长可延至 5 年                  |
| 低电量预警  | 剩余 ≤ 20% 报警  | 提前 1~2 个月预警换电                     |

### 5.3 通讯指标

| 指标项  | 目标值                   | 备注       |
| ---- | --------------------- | -------- |
| 协议   | 蓝牙低功耗                 |          |
| 节点类型 | 电池供电低功耗节点             |          |
| 频段   | 2.4 GHz               | ISM      |
| 通讯距离 | ≥ 30m 空旷 / 室内穿墙 1~2 层 | 视天线与部署环境 |

### 5.4 环境与可靠性

| 指标项  | 目标值                                     |
| ---- | --------------------------------------- |
| 工作温度 | -20 ~ +60℃（主机）（低于 -10℃ 工况需搭配宽温纽扣电池）     |
| 存储温度 | -30 ~ +70℃                              |
| 相对湿度 | 5% ~ 95% RH（无凝露）                        |
| 防护等级 | 主机 IP20 (需刷三防漆)/ 钳环 IP40                |
| 绝缘耐压 | 钳环开闭面绝缘耐压 ≥ 3000V AC / 1min，保障一次侧母线耐压安全 |

## 8. 认证与合规

- 无线电：SRRC 型号核准（中国）。
- EMC：GB/T 17626 系列
- 安规：电池运输
- 环保：RoHS 2.0。
- 计量：本产品采用**软件计量方式**，电量综合误差 ≤ ±10%，定位为"能耗展示与联动参考"（非结算级），不申办计量器具型式批准、不宣称贸易结算级计量。

## 10. 风险与开放问题

| 编号   | 风险/问题                               | 影响                    | 应对                                |
| ---- | ----------------------------------- | --------------------- | --------------------------------- |
| 10.1 | 开口钳式 CT 钳口闭合与定位偏差                   | 精度受气隙/位置影响            | 钳口闭合结构设计 + 标定，满足 ±3%（额定）/±5%（小信号） |
| 10.2 | 小电流量程精度不足（CT 低端非线性）                 | 低量程末端精度差              | 选型线性度 ≤0.2% + 量程分档适配实际电流          |
| 10.3 | 电量需电压、钳式无电压采集                       | 综合误差受电压/PF 偏差影响       | 软件计量 ±10% 非结算级；网关侧融合电压/功率因数修正     |
| 10.4 | 组网方案待定（标准 Mesh 需常电骨干 vs 自定义低功耗存储转发） | 影响架构与功耗               | 与研发专项对齐后定                         |
| 10.5 | 纽扣电池容量有限，续航难达 5 年                   | 换电频率升高                | 可换电池结构 + 极致低功耗；采样/上报周期权衡；电流磁环补能   |
| 10.6 | 休眠期无法检测电流，事件触发有延迟                   | 越限告警最坏延迟 ≈ 唤醒周期（3min） | 唤醒窗口内检测 + 合理唤醒周期，容忍分钟级延迟          |

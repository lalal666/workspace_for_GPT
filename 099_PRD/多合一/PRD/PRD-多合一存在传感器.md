# 2、产品概述

> 此份文档承接MRD，PRD经过评审后续需由BA/SE进行拆解到PDT的具体领域，没有BA/SE则由产品完成需求拆解。

## 2.1、产品简介

### 2.1.1、产品定义

 顺应公司层面的“源·网·**荷**·储”全链条战略，深耕于“**感**·通·算·控”核心技术，服务于“智慧楼宇”、“智慧照明”、“智慧暖通”、“智慧新风”等解决方案，规划了此产品--多合一存在传感器。

多合一存在传感器处于负荷端的感知产品线上，具备对周围环境中的 光照强度、温度、湿度、人体存在 信息进行**收集**、**转换**与**传递**功能。

## 2.2、需求背景/来源

源自MRD内多场景智慧能源解决方案中对室内环境感知的要求。

## 2.3、痛点

站在能源管控角度来看，当下的产品无法聚合性的收集环境中的关键信息，进而印象多种场景的调度策略的制定。但场景的不同会决定策略的不同，所以并不是都需要收集那么多的环境信息，因此我们拆成了4款SKU来分别应对不同场景。

- 温、湿度检测：检测环境中的温度和湿度，服务于暖通新风的控制策略
- 光照度检测：检测环境中和的光照强度，服务于智慧灯具策略
- PIR热释电被动红外：可被动的检测热量变化，可以判断是否有人经过，需要算法屏蔽小动物干扰
- 24G人存雷达：可主动检测静止人体的呼吸微动，服务于暖通新风的控制策略 & 智慧灯具策略
- IR LED主动红外控制：可主控控制带有IR LED接收器的空调等终端电气设备

## 2.4、用户画像

1. **智能化系统集成商（核心客户）**
   负责楼宇智能化项目方案设计、施工调试。痛点：传统 PIR 无法识别静止人体导致投诉、有线传感器**施工成本**高、电池款维护量大。需要一套自供电、多 SKU 组合的传感产品，按场景灵活选型，对接楼宇自控平台，稳定交付照明、暖通节能改造项目。
2. **甲方物业 / 能源运维负责人**
   楼宇运营管理方，核心诉求是降低照明、空调能耗，减少设备**巡检**、换电池等运维工作，实现空间人感、日光联动、空调自动化，满足**节能**管理要求。
3. **空间终端使用者**
   办公人员、酒店住客、师生。期望**无感智能**：人在灯光持续点亮、随自然光自动调节亮度、空调自动适配环境，避免灯光误关闭、照度不适等问题。

## 2.5、使用场景

|  | **主要模组** | **应用场景** |
| --- | --- | --- |
| **SKU 1** | PIR、<br>24G人存雷达、<br>BT、<br>弱光太阳能 | 办公室、会议室、客房。人久坐不动也维持有人状态，避免无故关灯；PIR 做低功耗唤醒，雷达负责静态存在，兼顾功耗和准确率，日光节能、空间占用统计。 |
| **SKU 2** | PIR、<br>BT、<br>弱光太阳能 | 走廊、过道、楼梯间。人经过触发，离开延时关灯；适合人不会长时间停留的区域，成本更低。 |
| **SKU 3** | 光照传感器、<br>温、湿度传感器、<br>BT、<br>弱光太阳能 | 办公室、教室。做日光补偿自动调光、环境联动（空调 / 新风），**不检测人**。 |
| **SKU 4** | IR LED、<br>温、湿传感器、<br>BT、<br>弱光太阳能 | 红外空调 / 中央空调控制器，蓝牙下发指令，IR 发射红外码控空调，附带环境温湿度采集，**不做人感、不做照度检测**。 |

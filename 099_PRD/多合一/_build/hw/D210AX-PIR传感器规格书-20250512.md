连接要求 连接 DOCI 这个脚的主控芯片 IO 口必须是能够切换为输入和输出。

数据操作步骤 1.DOCI 脚平时是准备数据的时候是低电平，所以 IO 口要设置为输入口，每当准备好一个数据， DOCI 脚就会输出高电平，当主控芯片检测到高电平就延时 T 引导这么长时间，将IO 口设置为输出口， 输出低电平，拉低 DOCI 脚。

2.引导电平结束以后，就是 25bit 的数据，每一 BIT 的数据都要发一个CLK 电平，首先是输出低 电平，延时时间是 T 低电平，接着是输出高电平，延时时间是 T 高电平，之后就将IO 口设置为输入口， 然后判断这一 bit 的是 0 还是 1，如果是低电平就是 0，如果是高电平就1，注意的是不同的主控芯片因 Symbol Min Typ Max T 引导 45us 50us 200us T 低电平 0.8us 1us 4us T 高电平 0.8us 1us 4us T 判断 5us 10us 20us

3.读完最后一个 Bit 之后，就可以将 IO 口设置为输入口。等待下一个数据的引导电平。注意的是， 每一笔数据都要读取，不然数据会有异常波动。

数据处理 Bit24~Bit9 一共 16 位组成有效的 PIR 数据，第 Bit24 为符号位，要得到连贯的数据波形，就需 要进行数据处理。接收到数据后，当这个 16 位的 PIR 数据大于 32767 就减去32768；如果这PIR数据是 小于等于 32767，就加上 32768，即可。

热释电红外传感器生产和使用注意事项 传感器内含高敏感度感应片，感应片敏感、轻薄、易碎，生产过程中要注意保护，不当的使用方 法可能会损坏传感器。 1.传感器中使用的红外线感应材料对热量比较敏感，敏感材料可能在高温下龟裂、丧失性能， 损坏之后，传感器误动作会很多或者无动作。使用波峰焊接时，建议的焊接温度是260°C，在高温区 停留时间应小于 5 秒。如果焊接过程中有预加热器，则必须采取相应措施避免传感器受到烘烤。传感 器除引线焊接处外，其它部分不宜经受 100°C 以上的高温。

2.使用烙铁手工焊接时，烙铁温度设置不高于 350°C，每个焊点焊接时间应控制在1秒左右，焊 接超过 3 秒一定会损坏传感器。建议使用 0.6mm 粗的焊锡丝，这样可以提高焊接速度，常用的1mm 粗的焊锡丝融化速度太慢，不利于操作。

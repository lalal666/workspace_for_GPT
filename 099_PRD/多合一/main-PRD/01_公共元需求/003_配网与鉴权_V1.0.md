# 003_组网与鉴权

# 01 术语表

| 术语             | 本文含义                                                             |
| -------------- | ---------------------------------------------------------------- |
| SR-XXXX        | 需求编号，S：Sub、R：Require                                             |
| 入网 | 设备接入项目的现场网络。 |
| BLE 广播 | LPN 发出的无线消息，供现场 BLE 接入节点发现待组网的 LPN。 |
| 入网鉴权 | 正式入网前核验设备的出厂身份，确认它是澜潮智能设备。 |
| 实机身份／机身 MAC | 实机身份是现场这台设备经核验确认的出厂身份。机身 MAC 用于把扫码申请与现场设备对应起来。 |

# 02 需求边界

## 2.1 适用范围

3. 本PRD作为通用元PRD，可被多种不同型号的主PRD引用。

4. 只适用于LPN设备。父节点设备不应参考此PRD。

5. 只适用于**OPV+超级电容** 和 **锂电池** 和 **USB** 组合供电的LPN设备。

## 2.2 前置条件

3. OPV需要有高效的光电转换效率。

4. 超级电容的容量应能够支持数十次的有效扫描。

5. **本PRD的需求大类为 4，即 SR-4XXX**

# 03 具体阐述

## 3.1 组网方式

| ID | 需求描述 | 优先级 | 对应领域 |
| --- | --- | --- | --- |
| SR-4101 | 1）**支持本地组网。** 未组网的 LPN 上电后主动发送 BLE 广播，由具备接入资格的现场节点发现并受理。<br>2）数据路径为「LPN ↔ 现场 BLE 接入节点 ↔ 本地网络」。现场完成设备鉴权并返回入网结果。公网断开时，只要现场网络正常，仍可完成本地组网。 | P0 | FW、网关／协议、TE |
| SR-4102 | 1）**支持小程序扫码组网。** 安装人用「澜潮智联」扫描 LPN 机身 MAC，选择项目并提交组网申请。云平台向目标项目的现场网络下发组网任务。<br>2）数据路径为「小程序 → 云平台 → 智能网关 → 现场主干 → BLE 接入节点 ↔ LPN」。现场针对扫码指定的设备办理入网，并经网关回传结果。小程序收到现场入网成功的结果后，显示「组网成功」。 | P0 | 微信小程序、云平台、网关／协议、FW、TE |

## 3.2 入网鉴权

| ID | 需求描述 | 优先级 | 对应领域 |
| --- | --- | --- | --- |
| SR-4201 | 1）**两种组网方式均须在正式入网前核验设备身份。** 系统根据可信的出厂身份确认申请接入的是澜潮智能设备，验证通过后才允许入网。<br>2）非澜潮设备、身份无法核实或核验失败的设备应被拒绝，并记录拒绝原因。 | P0 | 安全、FW、网关／协议、云平台、TE |
| SR-4202 | 1）**扫码申请须与现场实机一致。** 系统用机身 MAC 查找扫码指定的设备，并核验现场实机的身份。<br>2）扫 A 设备时，只有通过核验的 A 设备才能完成这笔组网申请。附近发现 B 设备时，A 的申请继续等待 A 出现或按超时处理。 | P0 | FW、网关／协议、云平台、微信小程序、TE |

验收覆盖四个场景：公网断开时澜潮 LPN 可本地入网，扫码指定的澜潮 LPN 可通过云端下发入网，非澜潮设备在两条路径上均被拒绝，扫 A 时发现 B 不会使 A 的申请显示成功。

# 01 术语表

| 术语    | 本文含义                                |
| ----- | ----------------------------------- |
| OPV   | OPV 是有机半导体做成的柔性薄膜太阳能电池，配合超级电容给元器件供电 |
| LPN   | 低功耗节点                               |
| 超容    | 超级电容                                |
| 备用电源  | CR2450锂电纽扣电池                        |
| USB接口 | USB接口可作为DEBUG和对内供电接口                |
|       |                                     |

# 02 需求边界

## 2.1 适用范围

1. 本PRD作为通用元PRD，可被多种不同型号的主PRD引用。

2. 只适用于LPN设备。父节点设备不应参考此PRD。

3. 只适用于**OPV+超级电容** 和 **锂电池** 和 **USB** 组合供电的LPN设备。

## 2.2 前置条件

1. OPV需要有高效的光电转换效率。

2. 超级电容的容量应能够支持数十次的有效扫描。

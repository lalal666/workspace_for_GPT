# 006_心跳机制

# 01 术语表

| 术语 | 本文含义 |
| --- | --- |
| 心跳 | LPN 定期向父节点发送的消息，用于确认设备是否可达，并报告实际运行周期。 |
| 最近有效通信时间 | 父节点最近一次收到该 LPN 实时、有效消息的时间，用于判断设备在线状态。 |

# 02 需求边界

适用于通过本地组网或小程序扫码组网接入的 LPN。心跳走「LPN → BLE 父节点 → 现场主干 → 智能网关 → 云平台」。本地收发和换父按 `002 通信与安全` 执行，允许随心跳上报的业务记录按 `004 事件机制` 执行。

# 03 具体阐述

## 3.1 心跳收发

| ID | 需求描述 | 优先级 | 对应领域 |
| --- | --- | --- | --- |
| SR-7101 | 1）LPN 完成入网后，按实际生效周期向父节点发送心跳。即使长时间没有人员活动或其他业务事件，仍按周期保活。<br>2）父节点记录设备身份、最近有效通信时间和实际心跳周期。实时有效的业务上报也可刷新最近有效通信时间。 | P0 | FW、网关／协议、TE |
| SR-7102 | 1）LPN 发送心跳时，可在同一次唤醒窗口接收父节点暂存的配置或对时信息，也可携带允许随心跳上报的记录。<br>2）需要即时上报的联动事件和关键告警按各自条件触发。 | P0 | FW、网关／协议、TE |

## 3.2 心跳周期与低电调整

| ID | 需求描述 | 优先级 | 对应领域 |
| --- | --- | --- | --- |
| SR-7201 | 1）各型号定义默认周期及可选范围。SKU2 低功耗档以 2 小时为评审基线，有较快失联发现要求的场景可评估 5～30 分钟的标准档。<br>2）低电时可按能源策略延长周期。设备报告实际生效的周期和调整原因，父节点及平台据此更新判定依据。运输模式按能源管理要求停发心跳。 | P0 | 产品、HW、FW、网关／协议、云平台、TE |

## 3.3 在线判定与恢复

| ID | 需求描述 | 优先级 | 对应领域 |
| --- | --- | --- | --- |
| SR-7301 | 1）收到 LPN 的实时有效消息后，确认设备在线。父节点可正常监测 LPN 时，连续 3 个应到周期未收到有效通信后判为离线，并按型号规定留出收发时间余量。<br>2）父节点失联或云端拿不到最新的现场判定结果时，平台显示「状态未知」，同时展示最近有效通信时间。 | P0 | FW、网关／协议、云平台、微信小程序、TE |
| SR-7302 | 1）断公网时，父节点继续完成现场保活和离线判断。恢复后，平台根据最新有效的现场结果更新状态。<br>2）重新收到 LPN 的实时有效消息后恢复在线。补发的旧心跳只进入历史记录。设备在线状态和人员存在状态分别展示。 | P0 | FW、网关／协议、云平台、TE |

## 3.4 验收场景

1. **长期无人活动。** LPN 仍按周期发送心跳，父节点持续确认在线。
2. **漏收与恢复。** 父节点正常时，漏收一两次后又收到有效通信，设备保持在线。连续漏收三个周期后显示离线，收到新消息后恢复在线。
3. **公网中断或父节点失联。** 公网中断时验证现场保活继续。平台拿不到有效现场结果时显示「状态未知」。
4. **低电延长周期。** 核对设备、父节点和平台显示的实际周期，确认离线判断随已生效的周期更新。
5. **断网补报。** 先送达旧心跳，再送达实时心跳，验证只有新的有效通信能让设备恢复在线。

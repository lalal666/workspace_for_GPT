# 002_通信与安全

# 01 术语表

| 术语                       | 本文含义                                                                  |
| ------------------------ | --------------------------------------------------------------------- |
| SR-XXXX                  | 需求编号，S：Sub、R：Require                                                  |
| 休眠叶节点（`HARVEST_LEAF`）    | 传感器在网络中的角色。平时休眠，唤醒后收发自己的数据。harvest代表从光获取能量。                           |
| `canRelay`／`maxHopDepth` | `canRelay` 表示是否承担报文转发，本文为 `false`。`maxHopDepth` 是声明的组网路径最大跳深，本文为 `3`。 |
| 父节点／直挂／换父                | 1）父节点是替休眠传感器收发和暂存消息的常电设备。

| BLE 广播／本地联动              | BLE 广播可在不逐台建立连接的情况下发送消息。本文用广播把有效事件送给同组灯具等执行端，现场可直接联动。                 |
| 广播 TTL                   | 限制广播可经多少跳转发的字段。本文的 SKU2 本地联动广播限制为 4 跳。                                |

| 配置读回／旧版快照                | 1）配置读回指从设备读取实际生效的配置。

| 近场维护                     | 授权人员在现场用手机通过 BLE 直连设备，查看状态、诊断或调整配置。                                   |
| GATT                     | 蓝牙通用属性规范，规定连接后怎样发现服务、读写数据和接收设备通知。本文用于手机直连维护。                          |
| MQTT／主题（Topic）           | MQTT 是消息发布和订阅协议。主题是消息按用途和权限分发所使用的名称，网关按授权主题收发消息。                      |
| TLS／MQTT over TLS／HTTPS  | TLS 用于加密传输和验证服务端身份。本文网关和云之间使用由 TLS 保护的 MQTT，小程序通过 HTTPS 访问云端接口。       |
| 链路层／应用层                  | 链路层负责在直接相连的设备间传送数据。应用层负责处理联动指令、配置和事件等业务消息。                            |
| 对端认证／来源认证                | 对端认证确认正在通信的另一端是谁。来源认证确认收到的业务消息来自哪个发送者。                                |
| 认证加密／AES-CCM             | 认证加密既保护报文内容，也检查是否被篡改。AES-CCM 是 BLE 链路层使用的一种认证加密方式，本文也将它列为应用层候选方案。     |
| 凭据／密钥轮换                  | 1）凭据是用来证明身份或权限的材料，例如密钥、证书或授权证明。

| 转译                       | **转译**就是转换协议或数据格式。比如网关把现场报文转换成云平台能接收的 MQTT 消息。                        |
| 组共享凭据                    | 同一组内多台设备持有的凭据，可用于验证组成员资格。具体发送设备仍按本文要求单独核验。                            |
| 防重放／业务去重                 | 1）防重放检查消息是否属于当前授权及有效会话，防止旧消息再次触发操作。
2）业务去重让同一指令或事件只执行或记录一次。           |
| 绑定代次／时效凭据                | 1）绑定代次是区分前后两次绑定的版本标记。
2）时效凭据用来证明报文仍在允许处理的范围内，例如受保护的会话序号。              |
| `evtSeq`／`eventId`       | 1）`evtSeq` 是灯侧用于联动去重的事件序号。
2）`eventId` 是上行事件的唯一标识，重传、补报和换路由沿用原值。      |

# 02 需求边界

## 2.1 适用范围

1. 本PRD作为通用元PRD，可被多种不同型号的主PRD引用。

2. 只适用于LPN设备。父节点设备不应参考此PRD。

3. 只适用于**OPV+超级电容** 和 **锂电池** 和 **USB** 组合供电的LPN设备。

## 2.2 前置条件

1. OPV需要有高效的光电转换效率。

2. 超级电容的容量应能够支持数十次的有效扫描。

3. **本PRD的需求大类为 3，即 SR-3XXX**

## 经验（可复用）

- **PDF 提取工具坑**：`workbuddy-pdf` CLI 对某些 PDF 静默失败（exit 0 但无输出，如 E54 规格书）。可用 `pip install pymupdf` 后用 `C:\Users\lc\.workbuddy\binaries\python\envs\default\Scripts\python.exe` 渲染页面/取文本（注意：`python` 与 pip 的目标环境不一致，需用该绝对路径的解释器）。
- **Word 视觉校验**：本机装有 MS Word（`C:\Program Files\Microsoft Office\root\Office16\WINWORD.EXE`），无 LibreOffice。可用 PowerShell COM `ExportAsFixedFormat($pdf,17)` 导出 PDF，再用 pymupdf 渲染逐页检查排版，效果可靠。
- **docx-js 排版要点**：标题样式需显式加 `keepNext: true` 防孤立标题；表格用小表时给非末行单元格加 `keepNext` 可实现"整表不跨页"。
- 用户明确要求"不可以有隐藏的换行符"：用 `pageBreakBefore` 段落属性替代 `<w:br w:type="page"/>`，全文 `<w:br>`/`<w:cr>` 归零；TOC 内的 `<w:tab/>` 是点线引导符，属正常。

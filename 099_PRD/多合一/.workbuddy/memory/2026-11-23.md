## 多合一传感器产品使用手册（4 SKU 通用）

- 产出：`用户手册/多合一传感器-产品使用手册_V1.0.md`
- 结构定稿（用户确认的 8 章）：产品简介 / 技术参数 / 使用须知 / 安装指引 / 注意事项 / 装箱清单 / FAQ 与售后服务 / 合格证
- 关键约定：
  - 手册为 4 款 SKU 通用版，差异统一用「仅 SKUx」标注 + 矩阵式参数表，不拆四个版本
  - 安装指引固定四段式：勘测 → 固定 → 上电入网 → 自检
  - 「换电池」并入注意事项（禁忌 + 维护），未单列章节
  - 无目录、无文档控制章，仅保留封面信息表
- 型号与 MAC：SKU1 LC-S-MTS03-PR-11-001（42/C1）、SKU2 LC-S-MTS03-PR24-11-001（41/C1）、SKU3 LC-S-MTS04-TL-11-001（50/C1）、SKU4 LC-A-ACC03-IRTC-11-001（60/C2）
- 写作约束（源自 PRD 硬要求，后续修订须保持）：
  - SKU2 只写「有效触发角 120°（PIR）/ 有效保持角 150°（雷达）」，禁止写「探测角 150°」
  - 全系无可见工作灯，状态只能经小程序/平台查看
  - 「未知」态不等于「无人」，不得据此关灯
  - SKU4 红外为单向发射，界面显示的是推定状态，不得表述为真实状态
  - 手写留白项：服务热线、保修期限（以合同/保修卡为准）

# 品类与硬件验证

从使用条件和验收风险选用下列条目。共用平台能力统一引用基线，逐个 SKU 标注能力、选配、硬件变体及差异影响。明确标称参数、安装限制和对外承诺的依据。

## 按品类补齐

| 品类 | 需要关注的产品边界和工况 |
| --- | --- |
| 灯具 | 安装及电气接口，功率、光通量与工作面照度，调光范围及低亮表现，来电恢复，单灯与组控一致性。涉及恒照度时明确测量位置、传感器依赖、目标照度来源、收敛及传感器失效行为。涉及电量计量时明确测量来源、精度和适用负荷。 |
| 环境感知 | 区分移动、静态存在、温湿度和照度等实际能力。明确检测区域、安装高度或角度、遮挡与干扰、采样和上报、预热与校准、误判定义和适用人群或环境。对低功耗 SKU 验证休眠和唤醒对采集及控制时延的影响。 |
| 面板开关 | 区分纯无线、接线和是否直接切换负载。明确按键动作及判定窗口、反馈、单击和双击冲突、映射与重配、手动接管、断链和掉电恢复。直接驱动负载时定义额定负载、适用负载类型与保护需求。 |
| 空调控制器面板 | 明确受控机型、控制接口与接线或安装条件、可设置模式及温度范围、现场控制与远程调度的仲裁。定义控制器、室内机和外部反馈各能证明什么。根据接口验证响应、模式切换、状态一致性及异常时保护行为。 |

## 硬件约束与量产交付

- **供电与寿命。** 按供电类型考虑输入条件、峰值和稳态、功耗模式、掉电持久化及来电恢复。涉及微光采能时用「工作面或安装点照度与有效光照时长 × 典型与最不利触发频次」描述能量收支，并考虑光源、温度、切换、备用电源、寿命末期和重试负荷。注明电量是在何电压下计算，明确测算和实测的区别。若休眠设备仍承诺远程控制，核对接收窗口、响应分位数、能量代价及低电量降级。
- **安装与现场条件。** 定义设备尺寸或接口、安装面和空间、接线与施工约束、标定或对位位置、可维护性。按产品需要补充环境、机械、防护、温升和可靠性验证。引用结构图、接线图或安装 SOP 的版本。
- **成本、供应与批次。** 项目涉及量产时，记录目标成本及口径、关键件与可替代性、样品和量产配置差异、工艺和检测能力。变更关键模组时判断是否需要再做性能、兼容或认证验证，并核对宣传和售后资料。
- **市场准入与交付。** 由责任方确认目标市场、产品类别、认证范围和适用版本。将安规、EMC、无线、环保等适用事项连到责任人和验证材料。按阶段写清产测、工装、校准、标识、安装说明、包材箱内物料和售后诊断的交付及证据。

## 验收度量

| 指标 | 必须明确的条件 |
| --- | --- |
| 时延和成功率 | 事件起点和终点、时钟或仪器、并发与网络条件、样本量、分位数、超时和重试如何计入、实测动作与链路确认的区别。 |
| 检测与照度 | 检测区域、走位或静止时长、照度测点和参考仪器、干扰与光源、误报漏报的分母和统计时长。 |
| 功耗与寿命 | 输入功率或照度、工作与休眠占比、触发频次、供电或电池条件、温度、测量点和推算假设。承诺寿命时给出适用边界及降级或维护条件。 |
| 规模与可用性 | 设备数量及密度、同步触发与离线补报负载、工具和版本、失效后的能力保留、恢复时间与数据缺口。 |
| 节能效果 | 实测计量或估算口径、基准策略和统计周期、同类业务运行时间或占用条件、异常缺测处理，以及照明或暖通服务水平。明确报告能归因的范围。 |

按项目约定进入样机、联调、试产或现场交付。用阶段证据判断能否进入下一阶段，例如系统联调记录、功耗与能量实测、兼容性报告、签核的安装和产测资料。给每项证据标注测试条件、版本与责任人。
